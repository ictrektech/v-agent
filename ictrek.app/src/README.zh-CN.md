# v-Octop

基于 Octop 的 VOS AI 助手。每位用户拥有独立的专家、会话、记忆、数据库和工作区。

## 使用

1. 在 VOS 中打开 v-Octop，平台身份自动接入，无需注册或再次登录。
2. 选择默认助手或创建专家，直接描述任务。
3. 在对话中查看工具执行过程，在专家工作区管理生成的文件。

## 模型

在 V-Scheduler 中配置模型后，v-Octop 每分钟自动刷新当前 VOS 用户可见的模型。支持聊天、Responses 和 Messages 接口，无需填写模型 API Key。视觉模型保留图片输入能力。纯文本补全模型不进入 Agent 工具执行列表。

## VOS 应用

内置 V-Office、AI 相册、HybRAG 和 Image Studio 技能及 MCP 工具，沿用当前 VOS 用户授权，无需重复登录。对应应用需已安装，并允许此应用的 OIDC 客户端；未安装、服务不可用或没有权限时会明确报错。第三方云服务连接器仍按各自的授权方式接入。

每位 VOS 用户使用独立 Linux 账号、挂载与 PID 命名空间及 Octop 进程。工作区只属于当前用户；平台令牌保存在网关内存中，不交给 Agent。执行网络与应用容器共享，下游服务继续检查用户权限。

Octop 1.0.3b5 新增共享专家对话、知识库文档和文件夹移动，以及自定义 MCP 的 OAuth 应用凭证。到「专家 → 专家市场」安装模板，进入共享专家可打开共享对话。在知识库中从文档或文件夹的操作菜单选择移动。如果 MCP 服务器要求预注册 OAuth 应用，进入专家的「连接器 → 自定义 MCP」，填写服务方提供的客户端凭证。登录后打开[应用 API 参考](/app/com.ictrek.v-octop/api/docs)，可查询当前版本的路由和字段。
