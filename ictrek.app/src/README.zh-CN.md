# v-agent

基于 Octop 的 VOS AI 助手。每位用户拥有独立的专家、会话、记忆、数据库和工作区。

## 使用

1. 在 VOS 中打开 v-agent，平台身份自动接入，无需注册或再次登录。
2. 选择默认助手或创建专家，直接描述任务。
3. 在对话中查看工具执行过程，在专家工作区管理生成的文件。

## 模型

在 V-Scheduler 中配置模型后，v-agent 每分钟自动刷新当前 VOS 用户可见的模型。支持聊天、Responses 和 Messages 接口，无需填写模型 API Key。纯文本补全模型不进入 Agent 工具执行列表。

## VOS 应用

内置 V-Office、AI 相册、HybRAG 和 Image Studio 技能及 MCP 工具，沿用当前 VOS 用户授权，无需重复登录。对应应用需已安装，并允许此应用的 OIDC 客户端；未安装、服务不可用或没有权限时会明确报错。第三方云服务连接器仍按各自的授权方式接入。

每位 VOS 用户使用独立 Linux 账号、挂载与 PID 命名空间及 Octop 进程。工作区只属于当前用户；平台令牌保存在网关内存中，不交给 Agent。执行网络与应用容器共享，下游服务继续检查用户权限。
